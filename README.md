# Salsabeel Dar Aqel - Nursing Education Portfolio

Static site (HTML, CSS, JS). No build step.

## Publish on GitHub Pages
1. Create a repository, e.g. `portfolio`, and upload all files in this folder (keep `assets/`).
2. Settings > Pages > Source: **Deploy from a branch**, branch `main`, folder `/ (root)`.
3. Your site appears at `https://<username>.github.io/<repo>/`.

Edit text directly in the `.html` files; styles are in `assets/style.css`.
